# F47 L3 Gold Standard Audit

F47 is eligible for L3 promotion only when all of the following are evidenced on the exact promotion head:

- five substantive API engineering agents
- explicit fail-closed release governance
- contract/schema, compatibility, authentication, authorization, rate-limit, validation, error-contract, observability, SLO, rollback, and test gates
- unresolved breaking changes, conflicts, or questions block release
- human approval required and unable to override blockers
- unit/integration/adversarial governance tests
- separate eight-scenario held-out reproducibility suite with 100% expected-behavior pass rate
- clean-checkout minimal and complete examples
- Python 3.10, 3.11, and 3.12 CI green
- held-out artifact published
- MIT license, citation metadata, reproducibility and security documentation

L3 is a reference-quality maturity designation, not a claim of universal production correctness.
